# Reference Notes — poster-video-from-audio（海报 + 口播 → 烧字幕）

30 期（ep01~ep30）实战沉淀。**动手前必读 1、3、4、5、6、7。**

## 坑位清单

### 1. 入口先 ffprobe 验时长（最高优先级的坑）

收到音频**第一件事**就是验时长，`<60s` 基本是传输/导出截断，直接退回重要源文件。
踩过两次：ep14 收到 6.6s 截断文件、ep21 同样 6.6s，都是白跑一轮 ASR 才发现。
`prep.sh` 已内置该检查（<60s 直接退出）。

### 2. opencc 命令行已失效，用 venv 里的 python 包

2026-10-02 起本机 `opencc` CLI 报 command not found。改用：

```python
# /Users/jx/.workbuddy/binaries/python/envs/default/bin/python
import opencc
cc = opencc.OpenCC('t2s')
```

脚本化为 `scripts/t2s.py`。**必须在修错词之前转简**（见坑位 3）。

### 3. FIX 替换对必须写简体（转简之后才匹配）

opencc 先转简，再修错词。若 FIX 写成繁体原文，转换后匹配不到会**静默漏修**。
ep19 踩过：写「間接」去修，转简后文件里是「间接」，漏修残留到渲染前才 grep 抓到。
修完必跑残留 grep 复查。

### 4. 歧义词必须用长串定向替换，不能全局替换

同一个词可能一次错一次对。ep30 实例：「亲戚」出现 2 次——
- 「在亲戚朋友面前证明自己」✅ 合法，不能动
- 「非常亲戚的描述」❌ 应为「清晰」

解法：FIX 写 `非常亲戚的描述=>非常清晰的描述` 这类**带上下文的长串**，
不要用 `亲戚=>清晰` 全局替换。同理「选举」（ep30 里 2 次全是「旋钮」的错听）
要先 grep 数出现次数再决定能不能全局换。

### 5. 经历 / 精力 同音混淆：方向不定，逐条判断

这两个词互相混淆且**方向不固定**（ep14 双向混淆 4 处），禁止全局单向替换。
ep30 实例：「把你的经历聚焦在核心的人类价值上面」→ 应为**精力**（此处指注意力投放，
不是过往经验）。按句意判断。

### 6. 渲染一律 run_in_background（前台 2 分钟上限必挂）

- ep25（27min）：前台超时 exit 137
- ep29（8'36"）：**同样**前台超时 exit 137（带 276 条 drawtext 滤镜链，实际渲染 6m23s）

结论：**别再按时长判断，所有渲染都后台跑**。参考耗时：8min 片 ≈6 分钟，
27min 片 ≈10.5 分钟。ASR 同理（27min ≈4.5 分钟）。

### 7. 品牌口播裁剪点每期不同，必须逐期看 SRT

已见三种长度，不要沿用上期数值：

| 形态 | SHIFT |
|---|---|
| 仅「欢迎收听豆包AI博客节目」+ 静音间隙 | 7.100s（ep30） |
| 「豆包AI播客节目」+ 简短问候 | 7.0~7.2s（ep13~ep28 多数） |
| 「豆包AI播客节目」+ 「哈喽大家好欢迎收听我们的播客」两段 | 9.800s（ep29） |

过滤词表：豆包 / 逗包 / 豆胞 / 播客节目 / 博客节目。
SHIFT 取**正式内容首段起点**（而非品牌段结束），可顺带裁掉中间的片头音乐/静音。

### 8. 结尾水印三种形态（无则跳过）

「字幕by索兰娅」「字幕:J Chong」「(字幕製作:貝爾)」。
按段落过滤删除 + 音频 `-t` 裁到该段起点前。ep29/ep30 都没出现，属偶发。

### 9. AI 读不了帧图时的验证替代法

本环境模型可能不支持读图（ep30 抽帧返回「不支持图片」）。可靠验证改为两条：
1. **帧文件生成成功**（`ls -la chk_*.jpg` 有正常体积）
2. **时间轴 grep 核对**：拿抽帧秒数去 `subs_trim.srt` 里查该时刻应有哪段字幕，
   与预期对照（如 t=830 → 「然后给他非常清晰的一些指示」，对应段 829.5~831.66）

另外结尾帧常无字幕属正常（末段字幕结束时间早于音频收尾几秒）。

### 10. 无法核实的专有名词：保留原样，不瞎猜

ASR 给出的工具名/平台名若无法确认正确写法（ep30 的「一定」「Edan」），
保留原样并在交付时说明，让用户补正确名称。瞎猜会引入错误信息，比留着更糟。

### 11. 其它已验证约束

- 跑 python 前必须 `unset PYTHONPATH`（WorkBuddy shim 会拖死进程，症状 exit 137 / import 卡死）
- `srt2drawtext.py` 必须用带 jieba 的 venv（`/Users/jx/.workbuddy/binaries/python/envs/default`），
  系统 python 无 jieba 会**静默回退**到硬切折行（把词拆开）
- whisper 必加 `--max-context 0`，否则可能出现幻觉（重复短语、时间戳全落 5s 整数倍）
- 字幕链用 `paste -sd ','` 合并，每行末尾不能有逗号
- ffmpeg 4.4 本机不支持 `scale=...:force_original_aspect_ratio=`，直接 `scale=1080:1920`
